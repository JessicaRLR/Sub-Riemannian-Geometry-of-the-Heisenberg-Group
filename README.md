## Project Overview

This undergraduate research project develops the differential and metric geometry of the three-dimensional Heisenberg group $\mathbb{H} = (\mathbb{R}^3, \cdot)$ from first principles. Starting from its Lie group structure, left-invariant vector fields, and canonical contact 1-form, the notes construct horizontal lifts of planar curves, prove global horizontal connectivity via Chow's theorem, and solve Dido's isoperimetric problem to characterize sub-Riemannian geodesics as horizontal lifts of circular arcs.
